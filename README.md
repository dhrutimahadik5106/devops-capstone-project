
# DevOps Capstone Project

## Project Overview

This project demonstrates the development and deployment of an Accounts REST API microservice using DevOps practices.

## Build Status

![CI Build](https://github.com/dhrutimahadik5106/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

## Features

- Create accounts
- List accounts
- Read account details
- Update accounts
- Delete accounts
- Automated testing with nosetests
- Code linting using Flake8
- Containerization with Docker
- Kubernetes deployment
- CI/CD automation
